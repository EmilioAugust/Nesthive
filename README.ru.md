# 📂 Nesthive (Менеджер закладок)

**Nesthive** — это веб-приложение для сохранения, организации и управления вашими любимыми ссылками.  
Построено на **FastAPI**, **SQLAlchemy** и **JWT-аутентификации**, позволяет пользователям создавать коллекции, добавлять теги к закладкам и легко выполнять поиск.

---

## Возможности

- **Аутентификация пользователей (JWT)** — надёжная регистрация и вход в систему
- **Закладки** — добавление, редактирование и удаление сохранённых ссылок
- **Теги** — категоризация закладок для удобной организации
- **Поиск и фильтрация** — находите ссылки по ключевым словам или тегам

---

## Технологический стек

- **Backend:** FastAPI
- **Frontend:** React, Vite, JavaScript (ES6+), CSS, Fetch API
- **База данных:** PostgreSQL
- **ORM:** SQLAlchemy
- **Авторизация:** JWT (python-jose) + Passlib

## Требования

---

## 🐳 Запуск с помощью Docker

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/EmilioAugust/Nesthive.git
cd Nesthive
```

### 2. Настройте переменные окружения
```bash
cp .env.example .env
# Отредактируйте файл .env, указав свои значения
```

### 3. Запустите все сервисы
```bash
# Первая сборка и запуск
docker-compose up --build
# или
# Запуск в фоновом режиме
docker-compose up -d --build
```

### 4. Откройте приложение в браузере
- Frontend: http://localhost:5173
- Backend API: http://localhost:8000/docs
